ДЕЛОВОД — система аналитики планёрок. Демонстрационная версия

Локальный запуск: распакуйте архив целиком и откройте index.html в браузере.
Публикация: загрузите в одну папку сайта index.html, style.css, app.js, favicon.svg и папку assets (логотипы и иконки процесса).
Вход в кабинет: кнопка «Войти без ввода данных».
Полный сценарий: «Загрузка записи» → «Запустить сценарий» → «Очередь проверки» (подтвердить срок доставки шёлка).

Данные вымышленные: верфь «Северный ветер». Авторизация, обработка записи и доставка сообщений имитируются.
Изменения сбрасываются после перезагрузки страницы.
Шрифты Unbounded, Manrope, Jost и JetBrains Mono загружаются из Google Fonts; без интернета используются системные.
